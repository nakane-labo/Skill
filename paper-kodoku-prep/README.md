# 論文購読プレップ（paper-kodoku-prep）

ゼミの論文購読（輪読・抄読会・ジャーナルクラブ・論文紹介）の事前準備を、対話型クイズと発表スライド作成までガイドするスキルです。

AI に要約だけもらって終わりにしない。選択式クイズと問いかけで **1ステップずつ** 進み、本文・図表を自分で探して答えさせ、最後に発表用スライド（.pptx）まで仕上げます。全部通すと **1〜2時間** かかりますが、途中で切っても **進捗メモ** で再開できます。

## こんなときに使う

- ゼミの輪読・抄読会・論文紹介の発表準備
- 論文 PDF を渡して「読み解きたい」「理解度を確認したい」
- IMRAD 形式で要約しながら精読したい
- 前回の「進捗メモ」を貼って「続きから」再開したい

## 対応範囲

| 種類 | 記号 | 例 |
|------|------|-----|
| 量的研究 | A | アンケート調査、実験研究 |
| 質的研究 | B | インタビュー、M-GTA、事例研究 |
| 混合研究法 | C | 質量併用 |
| レビュー・理論・制度分析 | D | 制度分析、理論的考察 |
| 英語論文 | — | 段落単位で一緒に読むモード（全文訳は渡さない） |

論文タイプに応じて STEP 2〜4 の問いが自動で差し替わります。詳細は `references/paper_types.md` を参照。

> **本の1章の輪読**は姉妹スキル [`booksection-rindoku-prep`](../booksection-rindoku-prep/) を使います。

## 進め方（STEP 0〜7）

| STEP | 内容 |
|------|------|
| 0 | ウォームアップ（タイトルから内容を予想） |
| 1 | 問い（Introduction）を当てる |
| 2 | 方法（Methods）を読む ※タイプ別 |
| 3 | 結果（Results）を読み取る ※タイプ別 |
| 4 | 考察と批判的吟味 ※タイプ別 |
| 5 | 用語チェック |
| 6 | まとめ＋成果物（レジュメ＋発表スライド .pptx） |
| 7 | スライド理解チェック（説明できるか確かめる） |

各ステップは **一度に1つずつ**。要約を先に全部出しません。

### 主な機能

- **本文・図表に戻らないと答えられないクイズ**を中心に出題（選択式 A/B/C/D）
- **正解の位置をランダムに散らす**（同じ選択肢ばかり正解にならないよう配慮）
- **学年別サポート（1〜2回生限定）**：自由記述の問いで答えが不十分なとき、語句の断片を並べて自分の言葉で組み立てさせる補助
- **中断と再開**：「今日はここまで」と言われたら進捗メモを出力。次回メモを貼って「続きから」で再開
- **英語論文モード**：対話は日本語、キーワードは「原語（訳語）」併記。全文訳は渡さず段落単位で読む
- **STEP 7 の発表者確認**：スライドに載せる表現は発表者本人が理解できているか最終確認

4. 中の `paper-kodoku-prep` フォルダだけを使う

ZIP の直接リンク（main ブランチ）:

## 使い方

論文 PDF をエージェントに渡し、例えば次のように依頼してください。

- 「この論文の購読の準備をしたい」
- 「輪読会の発表準備を手伝って」
- 「IMRAD で要約しながら理解度を確認したい」
- 「前回の進捗メモを貼るので、続きからお願いします」

急いでいる場合は「クイズは省いて要約だけ」と言えば、対話を省いてレジュメ＋スライドを直接作るモードにも切り替わります（基本は対話を推奨）。

### 進捗メモの例

途中で終わらせたとき、スキルが次のようなメモを出します。次回このまま貼り付けて「続きから」と言えば、STEP 0 からやり直さず再開します。

```
📋 進捗メモ（次回このまま貼り付けて「続きから」と言ってください）
- 論文：著者名（年）「タイトル」
- 論文タイプ：量的／質的／混合／レビュー・理論
- 完了：STEP 0〜3
- 次回：STEP 4（考察と批判的吟味）から
- よくできていた点：…
- 引っかかった点：…
- メモ：分野=社会福祉学／学部3回生／発表日=7/15
```

再開時は論文 PDF の再添付が必要です（新しいチャットでは前回のファイルは見えません）。
