# 本輪読プレップ（booksection-rindoku-prep）

ゼミの「本の輪読」（書籍・テキスト講読・章担当発表）の事前準備を、対話型クイズと発表スライド作成までガイドするスキルです。

担当章だけをつぎはぎで読ませない。**本全体の中での章の位置づけ**と、前の章・次の章との接続を意識しながら、問いかけとクイズで **1ステップずつ** 進めます。担当章の準備は **1〜2時間**、聞く側の準備は **15〜30分** 程度です。

## こんなときに使う

| 場面 | 依頼の例 |
|------|----------|
| **担当章の発表準備** | 「第3章の輪読準備をしたい」「担当章のスライドを作って」 |
| **章の読み解き** | 「この章が本全体のどこに位置するか整理したい」 |
| **聞く側の準備** | 「今週は聞く側。質問を考えたい」 |
| **再開** | 前回の「進捗メモ」を貼って「続きから」 |

## 対応範囲

| 本のタイプ | 記号 | 例 |
|-----------|------|-----|
| 単著モノグラフ | M | 1つの調査・議論を本全体で展開 |
| 論集・編著 | E | 章ごとに著者が違う |
| 理論書・古典 | T | 理論の展開・古典の読解 |
| 教科書・概説書 | K | テーマごとに章が独立 |

STEP 2〜4 の問いはタイプ（M/E/T/K）で差し替わります。詳細は `references/book_types.md` を参照。

> **雑誌論文1本**の購読準備は姉妹スキル [`paper-kodoku-prep`](../paper-kodoku-prep/) を使います。論集の章でも、本の一部として渡されたらこのスキルで進めます。

## 進め方

### 担当章フロー（STEP 0〜7）

| STEP | 内容 |
|------|------|
| 0 | ウォームアップ＋本と章の位置づけ（書誌・目次・前章までの流れ） |
| 1 | この章の問い・ねらいを当てる |
| 2 | 議論の組み立て／方法を読む ※タイプ別 |
| 3 | 中身（主張・データ・概念）を読み取る ※タイプ別 |
| 4 | 批判的吟味＋他章・本全体との接続 |
| 5 | 用語チェック |
| 6 | まとめ＋成果物（レジュメ＋発表スライド .pptx） |
| 7 | スライド理解チェック＋想定問答 |

各ステップは **一度に1つずつ**。要約を先に全部出しません。

### 聞き手モード（担当じゃない週）

「今週は聞く側」「質問を考えたい」と言われたら、担当章フローではなく軽量版（15〜30分）に入ります。

1. その週の章を読んだか確認し、予想やざっくりサマリを言わせる
2. **聞く観点を3つ**渡す（ねらいの把握／前章との接続／自分の関心との交差）
3. **質問を2〜3個作らせて磨く**（明確化型・接続型・批判型・応用型）
4. 発表後は振り返り（理解の変化・議論の論点・次回の発表への教訓）

### 主な機能

- **章間参照のクイズ**：「第○章で述べたように」などの参照を手がかりに、本全体の流れを意識させる
- **推測の3区分**：「章に書いてあること」「目次・検索で分かったこと」「推測」を常に区別
- **目次の調査**：章 PDF だけでも、書誌情報があれば web 検索で目次を調べて進められる
- **学年別サポート（1〜2回生限定）**：自由記述の問いで答えが不十分なとき、語句の断片を並べて組み立てさせる補助
- **中断と再開**：進捗メモで別日に続きから。再開時は章 PDF の再添付が必要
- **STEP 7 の発表者確認**：理解できていない表現はスライドに載せないよう最終確認

## ダウンロード（Claude デスクトップ）

このスキルは **Claude デスクトップ**用です。カタログ全体（[`nakane-labo/Skill`](https://github.com/nakane-labo/Skill) の Code → Download ZIP）は使わないでください。3スキルが一緒に入るとアップロードに失敗します。

1. [booksection-rindoku-prep.zip](https://github.com/nakane-labo/Skill/releases/latest/download/booksection-rindoku-prep.zip) をダウンロードする（**解凍しない**）
2. Claude デスクトップで **Settings → Capabilities** の **Code execution and file creation** をオンにする
3. **Customize → Skills** → **+** → **Create skill** → **Upload a skill** で、いまの ZIP をアップロードする
4. 一覧のスイッチをオンにする
5. 新しいチャットを開き、担当章の PDF を添付する

ZIP の中は `booksection-rindoku-prep/SKILL.md` という形です。解凍して中身だけを再圧縮すると失敗します。

公式手順: [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## 使い方

担当章の PDF を Claude デスクトップに渡し、例えば次のように依頼してください。

- 「第3章の輪読準備をしたい」
- 「担当章の発表スライドを一緒に作って」
- 「この章が本全体のどこに位置するか整理したい」
- 「今週は聞く側。質問を考えたい」
- 「前回の進捗メモを貼るので、続きからお願いします」

章の PDF だけしかない場合、スキルは書誌情報や目次の確認を促します。手元の本の目次を教えてもらうか、web 検索で目次を調べて進めます。

### 進捗メモの例

```
📋 進捗メモ（次回このまま貼り付けて「続きから」と言ってください）
- 本：著者名（年）『書名』出版社
- 担当章：第○章「章タイトル」
- 本のタイプ：モノグラフ／論集／理論書・古典／教科書
- 完了：STEP 0〜3
- 次回：STEP 4（批判的吟味と他章接続）から
- 前章までの情報：…
- よくできていた点：…
- 引っかかった点：…
- メモ：分野=／学年=／発表日=
```
