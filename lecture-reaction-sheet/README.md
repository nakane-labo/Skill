# 講義感想シート作成ガイド（lecture-reaction-sheet）

大学の講義の感想シート（リアクションペーパー）作成を、学生が講義を十分理解し自分の言葉で書けるようになるまで対話的にガイドするスキルです。社会学を学ぶ学部2〜3回生を対象としています。

AI に感想文を代筆させて終わりにしない。理解度確認クイズ、日常体験との接続、他講義・社会学的概念との接続を経てから、学生自身の言葉で感想を書き上げます。**完成した感想シートを安易に渡さないこと**を最優先します。

## こんなときに使う

- 「感想シート」「リアクションペーパー」を書きたい
- 「講義の感想を書きたい」
- 講義資料（と、あれば音声/動画）をもとに理解度を確認しながら仕上げたい

## 全体の流れ（ゲート方式）

| 段階 | 内容 |
| --- | --- |
| 0 | 入力の受け取りと確認（講義資料のアップロードは**必須**） |
| 1 | 講義内容の把握とミニ要約の提示 |
| 2 | 理解度確認クイズ（選択式＋記述式）←ゲート1：完璧な正答まで通さない |
| 3 | 日常体験との接続を問う ←ゲート2：具体的な経験が確認できるまで通さない |
| 4 | 他講義・社会学的概念との接続を問う |
| 5 | 学生が自分の言葉で感想を書く（Claudeは代筆しない） |
| 6 | 採点基準に照らしたフィードバックと差し戻し |
| 7 | 提出前の最終確認クイズ ←ゲート3：理解しないまま提出させない |
| 8 | 学生自身の言葉のテキストを清書・提示 |

各段階のゲートを通過しない限り、次には進みません。「クイズを飛ばして完成版だけくれ」といった要求には応じませんが、終始サポーティブな態度を保ちます。

## 必要なもの

- **講義資料（必須）**：スライド、レジュメ、PDF、Wordなど。資料がない場合はスキルが作業を開始しません。
- **音声・動画データ（任意）**：あれば理解確認の精度が上がります。

## ダウンロード（Claude デスクトップ）

このスキルは**Claude デスクトップ**用です。カタログ全体（[`nakane-labo/Skill`](https://github.com/nakane-labo/Skill) の Code → Download ZIP）は使わないでください。他のスキルと一緒に入るとアップロードに失敗します。

1. [lecture-reaction-sheet.zip](https://github.com/nakane-labo/Skill/releases/latest/download/lecture-reaction-sheet.zip) をダウンロードする（**解凍しない**）
2. Claude デスクトップで **Settings → Capabilities** の **Code execution and file creation** をオンにする
3. **Customize → Skills** → **+** → **Create skill** → **Upload a skill** で、いまの ZIP をアップロードする
4. 一覧のスイッチをオンにする
5. 新しいチャットを開き、講義資料を添付する

ZIP の中は `lecture-reaction-sheet/SKILL.md` という形です。解凍して中身だけを再圧縮すると失敗します。

公式手順: [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## 使い方

講義資料を Claude デスクトップに渡し、例えば次のように依頼してください。

- 「感想シートを書きたい」
- 「講義の感想を一緒に仕上げて」
- 「リアクションペーパーの準備をしたい」
