# 卒論メタアナリシス・ナビ（meta-sotsuron）

卒業論文を「**従属変数が同じ論文を3本集めて比較し、考察する**」方法（比較文献研究／簡易メタアナリシス）で書く、産業社会学部の学部4回生以上の学生を対話でガイドするスキルです。これまでの学習履歴が体系的ではない学生も含まれることを前提に、統計や論文の読み方は必要になった時点でそのつど説明します。

AI に卒論を丸ごと書かせて終わりにしません。テーマ、従属変数、使う論文、比較の観点、考察の主張は**あなたが決め**、AI は選択肢の提示・用語の解説・表の整形を担います。最後に、あなたが出した執筆指示書をもとに **AI が10000字以上の IMRAD 形式の卒論を Word で文章化し、あなたがチェック**します。

## こんなときに使う

- 「卒論をメタアナリシスで書きたい」「論文3本を比較して卒論にしたい」
- 「秋から卒論を始める」「短い期間で卒論を仕上げたい」
- 「先生が用意したテーマで書きたい」「従属変数を決めたい」
- 前回の「進捗メモ」を貼って「続きから」

## 卒論の仕様

- 本文10000字以上
- 構成は IMRAD（序論・方法・結果・考察。結論は考察の最後の節）
- Word（.docx）で作成し、PDF で提出（12月第2週）

## 2つのルート

| ルート | 始める時期 | 期間と作業時間の目安 |
| --- | --- | --- |
| 通年ルート | 春学期から | 約30週・約44時間 |
| 秋学期ルート | 秋学期から | 約11週・約30時間（週3時間）。週ごとの締切つき |

秋学期ルートでは、先生が用意したテーマから選ぶのが基本です。途中で「短い道」に切り替えることもできます（10000字以上は変わりません）。

## 先生が用意したテーマ（5専攻×2テーマ）

| 専攻 | テーマ |
| --- | --- |
| 現代社会 | 地域への愛着はどこから生まれるか／大学生の孤独感は何と関係しているか |
| メディア社会 | ネット・SNSへの依存傾向／SNSを使うことで生じる疲れ（SNS疲れ） |
| スポーツ社会 | 大学運動部員のバーンアウト／プロスポーツ観戦者はなぜまた見に来るのか |
| 子ども社会 | 子どもの自尊感情／中高生の進学希望（教育期待）と家庭・学校・地域 |
| 人間福祉 | 介護職員の離職意向／家族介護者の介護負担感 |

各テーマに、無料で読める候補論文を3〜4本用意しています。自分で一からテーマを決めることもできます。

## 全体の流れ（関門方式）

| Phase | 内容 |
| --- | --- |
| 0 | いつから始めるか、週ごとの締切を決める |
| 1 | テーマと従属変数を決める |
| 2 | 論文を探し、3本そろえる |
| 3 | 3本を読み、抽出シートを埋める |
| 4 | 比較表を作る |
| 5 | 結果を整理する（希望者は効果量の統合も） |
| 6 | 考察を組み立てる |
| 7 | 執筆指示書 → AI が全文を Word で文章化 |
| 8 | 原稿チェック・口頭試問の準備 |

1回30分ずつ進めます。区切りごとに「進捗メモ」と、ゼミの Slack に貼れる3行の報告文が出ます（報告を送るかどうかは自分で決めてください）。

## 文献の扱い

AI が挙げた候補論文は、あなたが実物（PDF）を手に入れて AI が読めるようになるまで採用しません。卒論に載せるのは、AI が本文を読んだ文献か、あなたが実物を確認した文献だけです。

## ダウンロード（Claude デスクトップ）

このスキルは **Claude デスクトップ**用です。カタログ全体（Code → Download ZIP）は使わないでください。

1. [meta-sotsuron.zip](https://github.com/nakane-labo/Skill/releases/latest/download/meta-sotsuron.zip) をダウンロードする（**解凍しない**）
2. Claude デスクトップで **Settings → Capabilities** の **Code execution and file creation** をオンにする
3. **Customize → Skills** → **+** → **Create skill** → **Upload a skill** で ZIP をアップロードする
4. 一覧のスイッチをオンにする
5. 新しいチャットを開き、「卒論をメタアナリシスで書きたい」と話しかける

ZIP の中は `meta-sotsuron/SKILL.md` という形です。解凍して中身だけを再圧縮すると失敗します。

公式手順: [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## 中断と再開

区切りごとに出る「進捗メモ」を保存し、次回それを貼って「続きから」と伝えると、現在地から再開します（論文 PDF は再度添付してください）。

## 困ったときは

卒論の進め方は、ゼミの Slack で担当の先生に相談してください。気持ちの落ち込みや体調のことは、学生サポートルーム（研心館2階）などに相談できます。窓口の一覧はスキルの中の `references/support.md` にあります。

## 構成

```
meta-sotsuron/
├── SKILL.md
├── references/
│   ├── phase_guide.md        各 Phase の問い・選択肢・関門、秋学期ルートの週ごとの締切
│   ├── theme_catalog.md      先生が用意したテーマと候補論文（kintone から自動生成）
│   ├── extraction_sheet.md   抽出シートの様式と記入例
│   ├── synthesis.md          結果の整理と効果量の統合
│   ├── writing_imrad.md      字数配分・執筆指示書・Word 作成・チェックリスト
│   ├── concepts_mini.md      用語のミニ解説
│   └── support.md            配慮の原則と相談窓口
├── assets/progress_memo.md   進捗メモと Slack 報告の様式
└── scripts/
    ├── pool_effects.py       効果量の統合（発展層のみ）
    └── catalog_from_kintone.py  kintone の CSV からテーマ・カタログを作る（先生用）
```
