# 卒論メタアナリシス・ナビ（meta-sotsuron）

卒業論文を「**従属変数が同じ論文を3本集めて比較し、考察する**」方法（比較文献研究／簡易メタアナリシス）で書く学部4回生以上の学生を、対話でガイドするスキルです。これまでの学習履歴が体系的ではない学生も含まれることを前提に、統計や論文の読み方は必要になった時点でそのつど説明します。

AI に卒論を丸ごと書かせて終わりにしません。テーマ、従属変数、使う論文、比較の観点、考察の主張は**学生が決め**、AI は選択肢の提示・用語の解説・表の整形を担います。最後に、学生が出した執筆指示書をもとに **AI が10000字以上の IMRAD 形式の卒論を Word で文章化し、学生がチェック**します。

## こんなときに使う

- 「卒論をメタアナリシスで書きたい」「論文3本を比較して卒論にしたい」
- 「従属変数を決めたい」「卒論用の論文を探したい」
- 「抽出シート」「比較表」「効果量」「考察が書けない」
- 前回の「進捗メモ」を貼って「続きから」

## 卒論の仕様

- 本文10000字以上（目標11000字）
- 構成は IMRAD（序論・方法・結果・考察。結論は考察の最後の節）
- Word（.docx）で作成し、PDF で提出

## 3層構造

| 層 | 内容 | 対象 |
| --- | --- | --- |
| 必修 | 抽出シートと比較表による構造化された比較 | 全員 |
| 標準 | 結果の方向（正・負・なし）をそろえた整理 | 全員 |
| 発展 | 効果量の算出と統合（ミニ・メタアナリシス） | 数値がそろい、希望した学生のみ（任意） |

## 全体の流れと工数（関門方式）

| Phase | 内容 | 目安 |
| --- | --- | --- |
| 0 | オリエンテーション・週ごとの計画づくり | 1時間 |
| 1 | 問いを立て、従属変数を決める | 3時間 |
| 2 | 文献を探し、3本を選ぶ（検索記録が「方法」の章になる） | 6時間 |
| 3 | 3本を精読し、抽出シートを埋める | 12時間 |
| 4 | 比較表を作る | 4時間 |
| 5 | 統合する（発展層は＋3時間） | 3時間 |
| 6 | 考察を組み立てる | 5時間 |
| 7 | 執筆指示書 → AI が全文を Word で文章化 | 4時間 |
| 8 | 原稿チェック・口頭試問の準備 | 6時間 |
| 計 | | 約44時間 |

各 Phase の関門を満たすまで次へ進みません。提出時期は学生ごとに違うため、日程ではなく工数で管理します。

## 文献の扱い

AI が挙げた候補論文は、学生が実物（PDF）を手に入れて AI が読めるようになるまで採用しません。卒論に載せるのは、AI が本文を読んだ文献か、学生が実物を確認した文献だけです。

## ダウンロード（Claude デスクトップ）

このスキルは **Claude デスクトップ**用です。カタログ全体（Code → Download ZIP）は使わないでください。

1. [meta-sotsuron.zip](https://github.com/nakane-labo/Skill/releases/latest/download/meta-sotsuron.zip) をダウンロードする（**解凍しない**）
2. Claude デスクトップで **Settings → Capabilities** の **Code execution and file creation** をオンにする
3. **Customize → Skills** → **+** → **Create skill** → **Upload a skill** で ZIP をアップロードする
4. 一覧のスイッチをオンにする
5. 新しいチャットを開き、「卒論をメタアナリシスで書きたい」と話しかける

ZIP の中は `meta-sotsuron/SKILL.md` という形です。解凍して中身だけを再圧縮すると失敗します。

公式手順: [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## 中断と再開

セッションの終わりに「進捗メモ」が出力されます。次回はそれを貼って「続きから」と伝えると、現在地から再開します（論文 PDF は再度添付してください）。

