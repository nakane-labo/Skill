# フェーズ別ガイド

各Phaseに入る前に、そのPhaseの節を読む。問いは上から順に**1つずつ**出し、返答を待つ。
問いの文面はそのまま使ってよいが、学生の様子に合わせて言い換えてよい。
【選】は選択式、【記】は記述式、【探】は本文を探させる問い。

---

## Phase 0　オリエンテーション・計画づくり（通年1時間／秋学期0.5時間）

**ねらい：** ルートを決め、学生の出発点と使える時間を知り、週ごとの締切を一緒に作る。
事情（なぜこの時期から始めるのか等）は聞かない。

1. 【選】卒論の作業は、いつから始めますか？
   a. 春学期から（ゼミナールⅢから1年かけて）→ **通年ルート**
   b. 秋学期から（ゼミナールⅣ・卒業研究だけ）→ **秋学期ルート**
   c. わからない → 担当の先生に確認するよう伝え、確認できるまでは秋学期ルートで仮に進める
2. 【記】1週間に卒論に使える時間はどれくらいですか？（例：「週3時間」）
   就職活動などで週によって違う場合は、「少ない週」の時間を答えてもらう。
3. 【選】論文（学術論文）を最後まで読んだことはありますか？
   a. ある（何本か）　b. 授業で1本くらい　c. ほとんどない　d. わからない
4. 【選】英語の論文を読むことについて、近いのはどれですか？
   a. 辞書や翻訳を使えば読める　b. 要約くらいなら　c. かなり厳しい　d. 読んだことがない
   → c・d なら、Phase 2 で日本語論文中心の検索を勧める（英語を禁止はしない）。
5. 【選】統計（平均、相関、t検定、回帰など）について近いのはどれですか？
   a. 授業で習って少しわかる　b. 聞いたことはある　c. まったくわからない
   → 発展層の可否の参考にする。c でも卒論は書けることを必ず伝える。
6. 【選】あなたの専攻はどれですか？（テーマ・カタログを示すときに使う）
   a. 現代社会　b. メディア社会　c. スポーツ社会　d. 子ども社会　e. 人間福祉
7. 【記】（通年ルートのみ）気になっていること、興味のあることを、思いつくまま3つ挙げてください。
   秋学期ルートでは聞かない（Phase 1 でテーマ・カタログから選ぶため）。

**関門：** 計画カードを作り、学生に確認してもらう。

```
【計画カード】
・ルート：通年／秋学期
・専攻：
・使える時間：週○時間（少ない週）
・論文経験／英語／統計：
・関心のタネ：（通年ルートのみ）
・週ごとの締切：（下の表から）
```

### 秋学期ルートの週ごとの締切（12月第2週提出から逆算、約11週）

| 週 | 時期の目安 | やること（Phase） | この週の終わりにできていること |
|---|---|---|---|
| 1 | 9月下旬 | Phase 0〜1 | 計画カード、テーマと従属変数 |
| 2 | 10月第1週 | Phase 2 | 3本のPDF、検索記録 |
| 3 | 10月第2週 | Phase 3（1本目） | 抽出シート1枚 |
| 4 | 10月第3週 | Phase 3（2本目） | 抽出シート2枚 |
| 5 | 10月第4週 | Phase 3（3本目） | 抽出シート3枚 |
| 6 | 11月第1週 | Phase 4〜5 | 比較表、結果の方向の整理 |
| 7 | 11月第2週 | Phase 6 | 考察メモ |
| 8 | 11月第3週 | Phase 7 | 執筆指示書の承認、原稿 v1 |
| 9 | 11月第4週 | Phase 8 | 原稿チェック、修正 v2 |
| 10 | 12月第1週 | Phase 8 | 最終版、PDF 化、想定問答 |
| 11 | 12月第2週 | 提出 | 予備週（遅れの吸収用） |

週3時間で約30時間になる。使える時間が週3時間未満なら、ここで正直に伝え、
最初から基本ライン（短い道）にするか、先生に相談するかを選ばせる。

### 通年ルートの目安

春学期（約15週）で Phase 0〜3、秋学期（約15週）で Phase 4〜8 を目安にする。
使える時間から工数（約44時間）を割り、週ごとの締切を学生と一緒に決める。
合計時間が足りない場合は、削れる部分（発展層、序論の背景文献の量）と削れない部分（Phase 3・4・6）を示す。

## Phase 1　問いを立て、従属変数を決める（通年3時間／秋学期1時間）

**ねらい：** 関心を「何が、何に影響するか」の形に直し、従属変数を1つに決める。

### 最初の分かれ道

【選】テーマはどうやって決めますか？
- a. 先生が用意したテーマから選ぶ（**秋学期ルートの初期値**）→ 下の「1-A」へ
- b. 自分で一から決める（通年ルートの初期値）→ 下の「1-B」へ
- c. わからない → 秋学期ルートなら a、通年ルートなら「まず b を少しやってみて、決まらなければ a」と提案する

### 1-A　先生が用意したテーマから選ぶ

`references/theme_catalog.md` を読む。

1. 【選】Phase 0 で聞いた専攻のテーマを、「テーマ名」と「テーマの説明」だけで2つ示して選ばせる
   （論文リストや「比較の見どころ」はまだ見せない）。選択肢に「ほかの専攻のテーマも見たい」「どれもピンとこない」を入れる。
   - 「ほかの専攻も見たい」→ 全10テーマの名前だけを一覧で示す。
   - 「どれもピンとこない」→ 1-B に移る（秋学期ルートなら締切への影響を一言伝える）。
2. 【選】従属変数の確認。「このテーマで『結果として説明したいもの』はどれですか？」
   選択肢にカタログの従属変数を1つ混ぜ、ほかは原因側の変数や対象者にする（従属変数の意味の確認を兼ねる）。
   外れたら `concepts_mini.md` の「従属変数・独立変数」で解説してから、もう一度選ばせる。
3. 下の 1-B の問い5（測り方の予想）を出す。
4. 関門へ。

### 1-B　自分で一から決める

1. 【選】まず言葉の確認です。「従属変数」に近いのはどれだと思いますか？
   a. 原因として考えるもの　b. 結果として説明したいもの　c. 調査の対象者　d. わからない
   → 正解 b。`concepts_mini.md` の「従属変数・独立変数」で解説。
2. 【選】Phase 0 の関心のタネ①〜③のうち、一番「なぜだろう」と思うものはどれですか？
3. 【記】それについて「〇〇が△△に影響しているのではないか」の形で1文書いてください。
   書けなければ型を渡す：「（原因）が多い／高い人ほど、（結果）が（高い／低い）のではないか」
4. 【選】いま書いた文の「結果」の部分を取り出すと、従属変数の候補はどれですか？
   （学生の文から Claude が3〜4個の候補を作る。抽象度の違う候補を混ぜる。例：「幸福感」「生活満足度」「孤独感」「わからない」）
5. 【選】その従属変数は、研究でどう「測られて」いそうですか？
   a. アンケートの質問（尺度）　b. 統計データ（割合・件数など）　c. インタビューで語られた内容　d. わからない
   → 測定のイメージを持たせる。卒論では3本で従属変数の意味がそろっていることが大事だと伝える。
6. 【選】その従属変数を扱った論文は、たくさんありそうだと思いますか？
   a. たくさんありそう　b. 少しはありそう　c. わからない
   → 判断材料として、Claude が CiNii Research や J-STAGE の検索件数の目安を一緒に確認してもよい（検索語は学生に決めさせる）。
   ヒット数がごく少ない場合は、従属変数を一段広げる案を選択肢で出す（例：「若者の献血意欲」→「向社会的行動」）。

**関門：** 学生自身の言葉で次の2文が言えること。

```
【問いのカード】
・従属変数：
・この従属変数を選んだ理由（2文）：
・（仮の）原因側の候補：
```

## Phase 2　文献を探し、3本を選ぶ（通年6時間／秋学期2時間）

**ねらい：** 検索の手順と採用基準を自分で決め、記録を残す。**この記録が卒論の「方法」の章になる**ことを最初に伝える。

### 2-A　先生が用意したテーマを選んだ場合（短縮版）

1. `theme_catalog.md` のそのテーマの「候補」論文を示し、リンクから PDF を入手してもらう。
   入手方法がわからなければ、J-STAGE の論文ページの「PDF」ボタンを押す、と1行で説明する。
2. 下の 2-B の問い1・2・3 を短く行い、**同じ従属変数で1回は自分で検索させる**（J-STAGE か CiNii Research）。
   ヒット件数と、候補論文が検索結果に出てきたかを記録する（方法の章で「多数の中から基準に合う3本を選んだ」と書くため）。
3. 【選】採用基準を決める（2-B の問い4と同じ）。候補論文が基準に合っているかを学生に確かめさせる。
4. 候補3本のうち入手できないもの・基準に合わないものがあれば、「予備」と入れ替える。
5. 2-B の問い6〜8（従属変数を本文から探す、同じと言えるか、PDF のアップロード）を行う。
6. 関門へ。

### 2-B　自分でテーマを決めた場合

1. 【選】論文を探す場所として、使ったことがあるものは？（複数可）
   a. CiNii Research　b. J-STAGE　c. Google Scholar　d. 大学図書館のデータベース　e. どれもない
   → e なら、日本語は CiNii Research と J-STAGE、英語は Google Scholar から始めるよう勧め、使い方を3行で説明。
2. 【記】従属変数を表す言葉を、言い換えも含めて3つ以上挙げてください（例：「孤独感」「孤立感」「loneliness」）。
   → Claude は足りない言い換えを1〜2個提案してよいが、採用は学生が決める。
3. 【記】原因側や対象者を表す言葉を1〜2個決め、検索語の組み合わせを作ってください（例：「孤独感 AND 大学生」）。
4. 【選】採用基準を決めます。どの条件を入れますか？（複数可）
   a. 査読付き論文に限る　b. 発表年（例：2010年以降）　c. 対象者（例：日本の大学生）
   d. 研究方法（例：アンケート調査による量的研究）　e. 言語（日本語のみ／英語も含む）
   → 「なぜその条件にしたか」を一言ずつ言わせる。理由がそのまま方法の章に入る。
5. 学生に実際に検索してもらい（Claude が検索を手伝ってもよい）、次を記録させる。
   ```
   【検索記録】
   ・データベース名：　　検索日：
   ・検索語：
   ・ヒット件数：　→ タイトル・要旨で絞った件数：　→ 本文を見た件数：　→ 採用：3本
   ・除外した主な理由：
   ```
6. 【探】候補論文ごとに「従属変数は何か」を本文（要旨・方法）から探させ、ページを答えさせる。
7. 【選】3本の従属変数は「同じ」と言えますか？
   a. 言葉も測り方もほぼ同じ　b. 言葉は同じだが測り方が違う　c. 言葉が違うが意味は近い　d. わからない
   → a〜c ならOK（b・c は Phase 4 の比較の観点になると伝える）。意味がずれすぎていれば差し替えを検討。
8. 3本のPDFを会話にアップロードしてもらう。**PDFがそろうまで Phase 3 に進まない。**
   Claude はアップロードされた3本を通読し、Phase 3 の正解と根拠ページを手元で把握しておく（学生には見せない）。

**選び方の助言（学生が迷ったとき）：**
- 3本のうち少なくとも2本は同じ研究方法（量的同士など）だと比べやすい。
- 結果が全部同じ方向の3本より、1本だけ違う結果の組み合わせの方が考察を書きやすい。ただし、それを狙って選んだ場合は限界として書く必要がある（選択の偏り）。
- 卒論レベルでは「たくさんある中から基準で選んだ3本」であることを説明できればよい。系統的レビューほどの網羅性は求めない。

**関門：** 検索記録・採用基準（理由付き）・3本の書誌情報・3本のPDF。

## Phase 3　3本を精読し、抽出シートを埋める（通年12時間／秋学期9時間）

**ねらい：** 1本ずつ、共通の項目で中身を抜き出す。様式と記入例は `extraction_sheet.md`。
基本ライン（短い道）では、`extraction_sheet.md` の★印の必須8項目だけを埋める。
1本を1週間（30分×数回）で終えるペースを目安にし、1回の区切りで「何項目埋まったか」を伝える。

進め方（1本ごとに繰り返す）：
1. 【選】まず論文の種類を当てます。この論文は？
   a. アンケートなどの量的研究　b. インタビューなどの質的研究　c. 両方（混合研究法）　d. レビュー・理論　e. わからない
2. 抽出シートの項目を**1項目ずつ**【探】で聞く。「〇〇はどこに書いてありますか？ページと、書いてある内容を短く」。
   学生の答えを Claude が持っている正解と照合し、合っていれば記録、違っていれば探し直させる。
3. 数値項目（サンプル数、平均、相関、結果の方向、有意かどうか）は、**どの表の何行目か**まで答えさせる。
   表の読み方がわからない場合は、その表を例に `concepts_mini.md` の「表の読み方」で解説する。
4. 1本終わるごとに、【記】「この論文を2文で説明してください（何を調べて、何がわかったか）」を出す。言えたら次の論文へ。
5. 量的研究なら、**発展層の材料がそろっているか**を Claude が裏で確認しておく（`synthesis.md` の「発展層の可否判定」）。学生にはまだ伝えなくてよい。

**英語論文モード：**
- 学生にまず Abstract を読ませ、【選】「この研究の従属変数はどれ？」から入る。
- 学生が求めたら、段落単位で日本語訳を出してよい。ただし抽出項目の「どこに書いてあるか」は学生に探させる。
- Method / Results の定型表現（participants, measured, was associated with, significant など）を、その論文で出てきた順に小さな用語表にして渡す。

**質的研究の場合：** 数値項目の代わりに「主なカテゴリー・テーマ」「従属変数にあたる経験や状態がどう語られたか」を抽出する（`extraction_sheet.md` 参照）。標準層での「結果の方向」は、「促進的に語られた／阻害的に語られた／両方」で整理する。

**関門：** 抽出シート3枚がすべて埋まり、すべての項目に根拠ページがあること。3本それぞれを2文で説明できること。

## Phase 4　比較表を作る（通年4時間／秋学期3時間）

**ねらい：** 3本を横に並べ、共通点と相違点をはっきりさせる。
先生が用意したテーマの場合、`theme_catalog.md` の「比較の見どころ」を問いかけの手がかりに使うが、**答えとして先に言わない**。

1. 【選】比較の観点として、どれを表の行にしますか？（複数可、標準ラインは最低5つ、基本ラインは最低3つ。基本ラインでは a・d・f を勧める）
   a. 対象者（誰を調べたか）　b. サンプル数・調査時期・国や地域　c. 研究方法
   d. 従属変数の測り方　e. 原因側の変数　f. 主な結果（方向）　g. 研究者が述べた限界
   → Claude は不足があれば追加を提案するが、行を決めるのは学生。
2. 抽出シートから比較表を Claude が整形する（Markdownの表で提示）。学生に誤りがないか確認させる。
3. 【選】3本の「主な結果」を比べると、どれに近いですか？
   a. 3本とも同じ方向　b. 2本と1本で分かれる　c. 3本ともばらばら　d. わからない
4. 【選】比較表を見て、3本の**一番大きな違い**はどれだと思いますか？（学生が選んだ行から選択肢を作る）
5. 【記】なぜそれが一番大きな違いだと思ったか、2文で書いてください。

**関門：** 比較表の確認と、「一番大きな違い」とその理由。

## Phase 5　統合する（標準3時間、発展層は＋3時間）

詳細は `synthesis.md`。順番は次のとおり。

1. 標準層：結果の方向をそろえた整理表を作る（学生が各論文の方向を判定し、Claude が表にする）。
2. 【記】整理表から言えることを1文で書いてください（例：「3本中2本で、〇〇が多いほど△△が低いという結果だった」）。
3. 発展層の可否を伝える。可能な場合のみ【選】「効果量を計算して統合してみますか？　a. やってみたい　b. 今回はやめておく」。
   - 不可能な場合は、なぜできないか（数値がそろわない、質的研究が含まれる等）を1〜2文で伝え、それ自体を卒論の限界の材料にしてよいと伝える。
4. 発展層を選んだ場合は `synthesis.md` の手順に従う。数値の抽出は学生、計算は Claude（`scripts/pool_effects.py`）。

**関門：** 統合結果を学生が自分の言葉で説明できる（Claude が「このフォレストプロット／整理表から何が言えますか？」と聞いて確認）。

## Phase 6　考察を組み立てる（通年5時間／秋学期4時間）

**ねらい：** 「結果が一致した・食い違ったのはなぜか」を、比較表の行を手がかりに説明する。卒論の価値はここで決まる。
基本ライン（短い道）では、問い3の根拠は1つでよく、問い4（反論）は Claude が候補を1つ示して、学生は「答え方」を選択式で選ぶ。

1. 【選】結果の一致・不一致の理由として、比較表のどの行が一番効いていそうですか？
   a. 対象者の違い　b. 従属変数の測り方の違い　c. 研究方法の違い　d. 時代や国・地域の違い　e. わからない
   → e の場合は、比較表で違いが大きい行を2つ指して、「この違いで結果が変わりうるか」を一緒に考える。
2. 【記】選んだ理由で、結果の違いをどう説明できますか？「〇〇が違うので、△△になったのではないか」の形で1〜2文。
3. 【記】その説明を支える根拠を2つ挙げてください（比較表・抽出シートのどこか、または論文の考察の記述）。
4. 【選】逆に、その説明では説明しきれないことはありますか？
   a. ある（それは何？）　b. 思いつかない　c. わからない
   → b・c なら Claude が反論の候補を1つ示し、学生にどう答えるか考えさせる。
5. 【記】この比較からわかったことは、社会や実践にとってどんな意味がありますか？1〜2文で。
6. 【選】この卒論の限界はどれですか？（複数可）
   a. 3本しか比較していない　b. 論文の選び方に偏りがありうる　c. 従属変数の測り方がそろっていない
   d. 量的・質的が混ざっていて単純に比べられない　e. 効果量を統合していない　f. その他
7. 【記】今後どんな研究があるとよいか、1文で。

**関門：** 考察メモの完成。

## Phase 7　執筆指示書を作り、Claude が全文を文章化する（通年4時間／秋学期3.5時間）

詳細は `writing_imrad.md`。

1. 執筆指示書を、これまでの成果物から Claude が下書きし、**空欄（学生が決める項目）を1つずつ質問して埋める**。
   主な質問：タイトル案（選択肢3つから選ぶか自分で書く）、序論で一番伝えたい問題意識、背景で使う文献（学生が実物を確認したもの）、結論の一文。
2. 学生が執筆指示書を承認したら、Claude が `writing_imrad.md` の字数配分に従って全文を書き、docx スキルを読み込んで Word ファイルにする。
3. 文章化では、執筆指示書・抽出シート・比較表・考察メモに**ない内容を足さない**。足りないと気づいたら、書く前に学生に聞く。
4. 完成した .docx を渡し、字数（本文）を報告する。10000字未満なら、どの章をどの材料で厚くするかを学生に選ばせて加筆する。

**関門：** 執筆指示書の全項目が埋まり、学生が承認していること。

## Phase 8　原稿チェック・仕上げ・口頭試問準備（通年6時間／秋学期5時間）

**ねらい：** 学生がチェック役として原稿に責任を持てる状態にする。詳細なチェックリストは `writing_imrad.md`。

1. 章ごとに【選】で確認問題を2〜3問出す（例：「方法の章で、採用基準として書かれていないものはどれ？」）。答えられなければ、その章を読み直してもらう。
2. 【探】数値の照合：本文中の数値を Claude が3〜5個選び、学生に論文PDFの該当ページで確かめさせる。
3. 学生が直したい箇所を指示し、Claude が修正する（何度でも）。修正指示の出し方の例を渡す：「考察の2段落目の『〜』を、もっと短く」「結果の表1に調査年を追加」。
4. 参考文献リストと本文中の引用が一致しているか確認する。
5. AI利用の記載が大学・ゼミで求められている場合は、その様式に従って学生と一緒に書く（どの作業でClaudeを使ったか）。
6. 口頭試問の想定問答を5問作り、学生に口頭（文字）で答えさせる。例：
   - なぜこの従属変数を選んだのですか？
   - なぜこの3本なのですか？　選び方に偏りはありませんか？
   - 3本の結果の違いを一言で説明してください。
   - この卒論の一番の限界は何ですか？
   - もう1本論文を加えるなら、どんな論文を選びますか？
7. 最終版を Word で保存し、PDF で書き出すよう伝える（Word の「名前を付けて保存」→ PDF）。

**関門：** チェックリスト完了、想定問答5問に答えられること。最後に完了の進捗メモを出す。
