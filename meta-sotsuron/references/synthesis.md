# 統合の手順（Phase 5）

## 卒論での呼び方について

厳密な「メタアナリシス」は効果量の統計的統合を指す。必修・標準層だけの卒論は、
方法の章で「メタアナリシスの考え方にもとづく比較文献研究（3研究の構造化比較）」のように説明する。
発展層まで行った場合は「3研究による簡易的なメタアナリシス」と書いてよいが、
3本では統合結果が不安定であることを必ず限界に書く。学生にもこの違いを Phase 5 の冒頭で1〜2文で伝える。

---

## 標準層：結果の方向の整理（全員）

1. 学生に、抽出シートの「結果の方向」を3本分読み上げてもらう。
2. **向きをそろえる**：従属変数の向きが論文で逆の場合がある（例：「幸福感」と「抑うつ」、尺度の得点が高いほど良いか悪いか）。
   【選】「論文Bの従属変数は、得点が高いほど良い状態？悪い状態？」と確認し、必要なら向きを反転して記録する。
3. 整理表を Claude が作る。

| 論文 | 対象者 | 方法 | 結果の方向 | 有意か | 主な数値（あれば） |
|---|---|---|---|---|---|
| A（年） | | | 負 | 有意 | r = −.21 |
| B（年） | | | 負 | 有意でない | r = −.08 |
| C（年） | | | 関連なし | — | （質的） |

4. 学生に1文でまとめさせる。数え上げ（vote counting）だけで結論を強く言いすぎないよう注意する：
   「有意でない＝関連がない」ではないこと、サンプル数が小さいと有意になりにくいことを、必要なら一言添える。

---

## 発展層の可否判定（Claude が Phase 3 の後に確認する）

次の**すべて**を満たすときだけ発展層を提案する。

- 3本すべてが量的研究である（2本だけ量的なら、2本の効果量を並べて示すだけにとどめる案を出す）
- 3本の従属変数と原因側の関係が、同じ種類の効果量に換算できる
- 各論文に次のどれかがそろっている
  - 2群の平均・SD・各群のn → 標準化平均差 d（Hedges の g）
  - 相関係数 r と n → r（Fisher の z で統合）
  - 2×2の度数、またはオッズ比と95%信頼区間 → 対数オッズ比
- 3本とも同じ種類にそろえられる（d と r が混在する場合は換算できるが、学生には説明が難しいので、原則は同じ種類がそろうときに限る）

重回帰の標準化係数（β）しかない場合は、原則として発展層に進まない（統制変数が論文ごとに違い、比較できないため）。その旨を限界として書く材料にする。

---

## 発展層の手順

1. 【探】学生に、各論文の数値を表のどこから取ったか確認させる（抽出シート Q3 の再確認）。
2. Claude が `scripts/pool_effects.py` 用の入力（CSV）を作り、学生に数値の打ち間違いがないか確認させる。
3. Claude がスクリプトを実行し、次を出す：各研究の効果量と95%信頼区間、統合した効果量（ランダム効果モデル）、異質性（I²）、フォレストプロット（PNG）。
   研究数が3本と少ないため、統合効果の95%信頼区間は **Hartung-Knapp 補正の値を主に報告する**（通常のDL法の区間は狭く出すぎる）。補正後の区間がゼロ（ORなら1）をまたぐことが多いが、それ自体が「3本では確かなことは言えない」という正直な結果であり、考察の材料になると学生に伝える。
4. 学生に読み取らせる問い：
   - 【選】統合した効果の向きは？　a. 正　b. 負　c. ほぼゼロ
   - 【選】3本の結果のばらつき（I²）は？　a. 小さい　b. 中くらい　c. 大きい　（目安：25%・50%・75%）
   - 【記】フォレストプロットを見て、ほかの2本と違う動きをしている研究はありますか？それはなぜだと思いますか？（→ Phase 6 につながる）
5. 限界として必ず確認すること：3本ではランダム効果の推定が不安定、出版バイアスは検討できない、選び方に偏りがありうる。

### スクリプトの使い方

```
python scripts/pool_effects.py input.csv --out forest.png
```

input.csv の形式（どれか1種類にそろえる）：

```
# 相関係数
study,type,r,n
山田(2019),r,-0.21,412
佐藤(2021),r,-0.08,150
Lee(2020),r,-0.30,280

# 2群の平均差
study,type,m1,sd1,n1,m2,sd2,n2
山田(2019),smd,3.2,0.8,120,2.9,0.9,115

# オッズ比（95%信頼区間）
study,type,or,ci_low,ci_high
山田(2019),or,1.8,1.2,2.7
```

出力の効果量の意味（学生への説明用）：
- r：±.10 小さい、±.30 中くらい、±.50 大きい（Cohen の目安。分野によって違うと添える）
- g（d）：0.2 小さい、0.5 中くらい、0.8 大きい
- オッズ比：1 なら関連なし。1より大きい／小さいほど関連が強い
