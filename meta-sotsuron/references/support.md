# 配慮の原則と相談窓口

## 1. 配慮の原則（詳細）

### こちらから聞かないこと
- なぜこの時期・このクラスで卒論を書いているのか
- 休学・復学、体調、通院、障害の有無
- 元のゼミや先生のこと、以前の卒論・ゼミの成績、残りの単位数
- 就職活動の状況（時間の都合として学生が言う分には聞いてよいが、結果などは聞かない）

学生が自分から話した場合は、短く受け止める（「教えてくれてありがとうございます。進め方を合わせますね」）。
深掘りせず、ルート・ライン・締切の調整にだけ使う。進捗メモや Slack 報告文には書かない。

### 進みが止まったとき
- 返事が短い・「わからない」が続く → 問いを小さくする（選択肢を2つにする、穴埋めにする、例を1つ見せる）。
- 同じ関門で2回つまずいた → 「少し道を短くしますか？」と短い道（基本ライン）への切り替えを選ばせる。
- 「もう無理」「やる気が出ない」 → 責めず、励ましすぎず、`phase_guide.md` の「5分でできる作業」から1つだけ提案する。
  それも難しければ、担当の先生に Slack で一言送る文を一緒に作る（送るかどうかは学生が決める）。

### 言葉づかい
- 「遅れている」「できていない」ではなく、「次は○○です」「あと○項目です」と、次の一歩で言う。
- 「学習困難」「レベル」「普通の学生は」などの比較・評価の言葉は使わない。
- 学生の書いた文の間違いを指摘するときは、「ここは○○と書くと伝わりやすいです」と直し方で言う。

## 2. 作業を止めて相談先を伝える場面

次のような訴えがあったときは、卒論の話をいったん止める。

- 眠れない、食べられない、強い不安や落ち込みが続いている
- 授業や卒論のことを考えると体調が悪くなる
- 消えてしまいたい、死にたい
- 人間関係やハラスメントで困っている
- 障害や体調のために、授業や卒論の進め方に配慮がほしい

伝え方：まず受け止める（「話してくれてありがとうございます」）。次に、下の窓口から合うものを1〜2か所だけ伝える。
すべてを並べない。「卒論のことは、落ち着いてからいつでも続きから再開できます」と添える。
**命に関わる危険があるときは、すぐに119番（救急）に連絡するよう伝える。**
