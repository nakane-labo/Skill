# 社会学評論スタイルガイド（第3版）— deep-research 運用要約

正本は日本社会学会の **[『社会学評論スタイルガイド』第3版（PDF）](https://jss-sociology.org/bulletin/guide/)**。**細部・例文・例外は必ず PDF（および学会サイトの更新情報）に従う。** 本ファイルはエージェント向けの最低限の拘束のみを示す。

## 適用範囲（本スキル）

- **アノテーション付き書誌**、**レポート末尾の文献リスト**、**文献を列挙・表示する一切の出力**で、次のルールを**既定**とする。
- 英語・日本語・その他の言語の文献が混在する場合も、**書式はスタイルガイドの該当節**（欧文文献・邦文文献・外国語文献・電子資料など）に合わせる。

## 識別子（必須）

| 種類 | 必須 | 備考 |
|------|------|------|
| **学術雑誌の論文**（ジャーナル記事） | **DOI** | 付与されている場合は**必ず**文献情報に含める（`https://doi.org/...` 形式推奨）。未付与のみその旨を記し、可能なら URL やデータベース情報をガイドに従って示す。 |
| **単行本**（書籍） | **ISBN** | **必ず**含める（ハイフン表記はガイド・出版社表記に合わせる）。 |
| **書籍の一章** | ISBN（書籍全体）＋該当章情報 | ガイドの「収録文献」の書式に従う。 |
| **電子書籍・電子ジャーナル・ウェブ** | ガイド第4章・4.5節 | DOI / URL / アクセス日等は**ガイドの該当箇所**に従う。 |

## 各文献に揃える情報（フィールド）

表示・文献リストの1件あたり、種類に応じて次を**欠落なく**揃える（スタイルガイドの順序・表記ルールに従う）。

- **共通**: 著者名（表記ルールはガイド）、**年**（発行年）、**タイトル**（論文・書名・章題など該当するもの）。
- **雑誌掲載論文**: **収録雑誌名**、巻・号・ページ（ガイドの該当形式）。
- **書籍**: 出版地・出版社、版、**ISBN**。
- **翻訳・編集書の章**など: ガイドの該当節に従い、編者・書名・ページ範囲を含める。

## 本文中の引用

- 割注・文献注・短い引用・長い引用の区別、**「=」の使い方（文献リストでは用いない等）**は **スタイルガイド第3章** に従う。
- Markdown レポートでは、本文は読みやすさを保ちつつ、**最終的な文献リストとの対応**が一意に取れる表記にする。
